# pl 0.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** pl을 "레포 내 `docs/pl/` 히스토리 + 서브에이전트 역할 세션 + 기계적 검증 마감 + 스킬 범위 안전 훅"으로 재구성한 0.5.0을 만든다.

**Architecture:** 히스토리는 새 단일 헬퍼 `pl_history.py`(표준 라이브러리)가 레포 작업트리의 `<historyDir>`(기본 `docs/pl`)에 쓰고, 런타임 상태는 그 아래 `.runtime/`(자기 무시 `.gitignore`)에 둔다. 역할 세션은 두 호스트 모두 "이름 없는 서브에이전트 + agent ID 재개"로 통일되어 teammate 생명주기 문서가 사라진다. 안전 훅은 Python 판정기 `guard.py`로 재작성되어 스킬 frontmatter(리드)와 플러그인 훅(`--scope role`, 역할 세션만)에 등록된다.

**Tech Stack:** Python 3.10+ 표준 라이브러리(생성기·그 테스트만 3.11 `tomllib`), bash 3.2 호환 셸 하네스, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-20-pl-repo-history-design.md` — §16이 §15 이전의 teammate 전제를 덮어쓴다. §7.1 TaskCompleted 훅은 §16.1(호스트 TaskList 미사용)에 의해 **구현하지 않는다**.

## Global Constraints

- 런타임 헬퍼·훅은 Python 3.10 표준 라이브러리만. `jq` 의존 제거.
- 모든 셸 스크립트는 bash 3.2(macOS 기본)에서 동작. `timeout`이 없으면 `gtimeout`, 둘 다 없으면 perl 대체.
- 히스토리 파일명 `YYYY-MM-DD-<slug>.md`, 일련번호 금지, 공용 INDEX 파일 금지.
- 기능 노트 `status`는 frontmatter 한 곳에만: `in-progress | done | done-with-risks | blocked`.
- pl은 커밋·push·merge·deploy·외부 변경을 하지 않는다(사용자 명시 요청 제외). 리드 노트 frontmatter `status`는 손으로 고치지 않고 `close`로만.
- 역할 세션 spawn에 `name`을 넣지 않는다. 런타임 이름은 라벨.
- 두 `plugin.json` 버전 `0.5.0` 동기화. 커밋 메시지는 레포 관례(`feat(pl)!:`, `fix(pl):`, `test(pl-…):`, `docs(pl):`, `chore(pl):`) 한국어.
- 레포 루트 `.gitignore`는 건드리지 않는다.
- 오케스트레이터 SKILL.md는 500줄 미만, Standing Completion Contract는 앞 5000자 안.

## Review Focus

1. `historyDir: ../x` 또는 절대경로 또는 `.git/x` — `where`가 거부하고 exit 2, 아무것도 만들지 않는다. (Task 2)
2. 같은 날 같은 제목으로 `feature`를 두 번 — 두 번째는 기존 파일을 돌려주고 덮어쓰지 않는다; 제목이 다른데 슬러그가 같으면 exit 1. (Task 3)
3. `verify`가 untracked 산출물(`coverage.out`)을 남기는 명령 — 실행 후 지문이 기준이므로 바로 이어지는 `close --status done`이 통과한다. (Task 4)
4. `git commit -m "docs; see git reset --hard note"` — guard가 허용한다(인용문 안은 명령이 아니다); heredoc 본문의 `git reset --hard` 줄도 허용. (Task 7)
5. 플러그인 훅 `--scope role`에 `agent_type`이 없는 일반 세션 입력 — 즉시 allow, stdout 비어 있음, exit 0. (Task 7)

**Interfaces (Produces):**
```python
def extract_command(payload: dict) -> str | None     # tool_input.command | tool_input.cmd; list → shlex.join; unwrap one "bash|sh|zsh -lc|-c <str>"
def split_commands(cmd: str) -> list[list[str]]       # shlex(punctuation_chars=True); join backslash-newline; heredoc bodies excluded; separators ; && || | & newline; redirection tokens dropped; recurse into sh -c / eval / xargs / $( ) / backtick bodies
def strip_wrappers(tokens: list[str]) -> tuple[list[str], str | None]   # leading VAR=val (returns deny reason if GIT_CONFIG_PARAMETERS/GIT_CONFIG_COUNT mention core.hooksPath), env/command/exec/time/nohup/sudo, path → basename

def main(argv) -> int                                 # --scope role: allow unless payload agent_type matches ^pl:team-pl-; prints deny JSON (same shape as before) or nothing; exit 0 always; internal error → exit 0, nothing printed
```
